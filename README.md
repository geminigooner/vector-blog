# Latent Affairs

A blog where posts are arranged by meaning instead of date.

I wanted to see whether Gemini and I would arrange the same things in the same way, so I embedded my posts and let the model place them. This is what came out.

## How it works
Gemini text embeddings + SigLIP visual embeddings via a
Hugging Face Space, reduced to 2D with PCA.

## Stack
React, Firebase, deployed on Railway.
